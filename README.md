# Notification UX Designer

A web-based prototype for designing and experimenting with notification user interfaces (UI). This project explores different notification layouts, interactions, and design concepts through multiple HTML iterations.

## Features

- Multiple notification UI prototypes
- Progressive design iterations
- Lightweight and browser-based
- No installation or build tools required
- Easy to modify and extend

## Project Structure

```
Notification UX Designer 0.html
Notification UX Designer 1.html
Notification UX Designer 2.html
...
Notification UX Designer 11.html
```

Each HTML file represents a different version or iteration of the notification designer, allowing comparison between various UI concepts and improvements.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/Notification-UX-Designer.git
```

2. Open any of the HTML files in your preferred web browser.

No additional dependencies or installation are required.

## Purpose

This project was created to:

- Prototype different interface designs
- Experiment with layout and usability
- Iterate on notification interaction patterns
